# The column names `calculate_kinematics()` used

The column names
[`calculate_kinematics()`](https://animovement.dev/animetric/reference/calculate_kinematics.md)
used

## Usage

``` r
legacy_kinematics_names(data)
```

## Arguments

- data:

  A frame with the columns
  [`add_kinematics()`](https://animovement.dev/animetric/reference/add_kinematics.md)
  adds.

## Value

`data`, with `cumulative_distance` renamed `path_length`.
