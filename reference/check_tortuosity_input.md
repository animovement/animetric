# Check the input to the windowed tortuosity

Check the input to the windowed tortuosity

## Usage

``` r
check_tortuosity_input(data, window_width, call = rlang::caller_env())
```

## Arguments

- data:

  An anipoint.

- window_width:

  The window width asked for.

- call:

  The calling environment, for error messages.

## Value

`window_width`, as an integer.
