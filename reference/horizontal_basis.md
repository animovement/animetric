# The horizontal axes course is measured in

Course counts about the vertical by the right-hand rule, from the axis
after it in the cycle x, y, z.

## Usage

``` r
horizontal_basis(up)
```

## Arguments

- up:

  A unit vertical along one of the axes.

## Value

A list of two unit vectors, `first` (course 0) and `second` (course
pi/2).
