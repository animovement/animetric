# Add translational, and where defined rotational, kinematics

Add translational, and where defined rotational, kinematics

## Usage

``` r
kinematics_cartesian(data, vertical = NULL, min_step = 0)
```

## Arguments

- data:

  A Cartesian anipoint.

- vertical, min_step:

  See
  [`add_kinematics()`](https://animovement.dev/animetric/reference/add_kinematics.md).

## Value

The anipoint with added kinematic columns.
