# Sinuosity and E_max of a rediscretised path

Sinuosity and E_max of a rediscretised path

## Usage

``` r
path_sinuosity(position, time)
```

## Arguments

- position:

  A data frame of positions, one column per axis.

- time:

  The index.

## Value

A list of `sinuosity` and `e_max`, each a number.
