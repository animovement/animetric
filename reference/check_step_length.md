# Check a `step_length` argument

Check a `step_length` argument

## Usage

``` r
check_step_length(step_length, call = rlang::caller_env())
```

## Arguments

- step_length:

  See
  [`summarise_path()`](https://animovement.dev/animetric/reference/summarise_path.md).

- call:

  The calling environment, for error messages.

## Value

`TRUE`, invisibly.
