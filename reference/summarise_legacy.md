# What `summarise_aniframe(type = )` used to return

What `summarise_aniframe(type = )` used to return

## Usage

``` r
summarise_legacy(data, type, measures)
```

## Arguments

- data:

  An anipoint.

- type:

  `"kinematics"`, `"tortuosity"` or both.

- measures:

  `"median_mad"` or `"mean_sd"`.

## Value

A data frame with one row per group.
