# Check a `min_step` argument

Check a `min_step` argument

## Usage

``` r
check_min_step(min_step, call = rlang::caller_env())
```

## Arguments

- min_step:

  See
  [`add_kinematics()`](https://animovement.dev/animetric/reference/add_kinematics.md).

- call:

  The calling environment, for error messages.

## Value

`TRUE`, invisibly.
