# What `summarise_kinematics()` returned

What
[`summarise_kinematics()`](https://animovement.dev/animetric/reference/summarise_kinematics.md)
returned

## Usage

``` r
summarise_kinematics_legacy(data, measures)
```

## Arguments

- data:

  An anipoint.

- measures:

  `"median_mad"` or `"mean_sd"`.

## Value

A data frame with one row per group.
