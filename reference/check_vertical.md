# Check a `vertical` argument

Check a `vertical` argument

## Usage

``` r
check_vertical(vertical, call = rlang::caller_env())
```

## Arguments

- vertical:

  See
  [`add_kinematics()`](https://animovement.dev/animetric/reference/add_kinematics.md).

- call:

  The calling environment, for error messages.

## Value

`TRUE`, invisibly.
