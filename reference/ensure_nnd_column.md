# Ensure an argument names a single column present in the data

Ensure an argument names a single column present in the data

## Usage

``` r
ensure_nnd_column(data, value, arg)
```

## Arguments

- data:

  An aniframe.

- value:

  The supplied column name.

- arg:

  Argument name, for the error message.

## Value

`TRUE`, invisibly.
